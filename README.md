## 📌 نظرة عامة

**المشكلة:** يواجه خريجو الجامعات العراقية صعوبة في تحديد المسار المهني الأنسب بعد التخرج، مع غياب أدوات إرشادية ذكية تفهم تخصصاتهم وتقترح عليهم وظائف مناسبة بناءً على مهاراتهم واهتماماتهم.

**الحل:** نظام ويب متكامل يحلّل الملف المهني للخريج باستخدام خوارزميات تعلم الآلة (TF-IDF + Cosine Similarity)، ويولّد قائمة وظائف مرتبة حسب درجة الملاءمة، مع تفسير كل درجة ومكوّناتها، **إضافة إلى مساعد ذكي** يجيب على أسئلة الخريج حول الوظائف والمهارات.

**لماذا يعدّ هذا المشروع ذكاءً اصطناعيًا حقيقيًا؟**
- يستخدم **خوارزمية تعلّم آلي فعلية** (TF-IDF Vectorizer + Cosine Similarity) وليس مجرد `if-else`.
- يوظّف **Retrieval-Augmented Generation (RAG)** محليًا في المساعد الذكي.
- كل مكوّن **قابل للتفسير والتقييم** وليس صندوقًا أسود.

## ✨ الميزات الرئيسية

| الميزة | الوصف |
|---|---|
| 🎯 **محرك توصية مفسَّر** | كل توصية مصحوبة بدرجة من 100 وتفصيل 5 مكوّنات (تشابه دلالي، مهارات، تخصص، خبرة، قطاع) |
| 💬 **مساعد ذكي (Chatbot)** | يصنّف نية السؤال (Intent Classification)، ويسترجع المعلومات من قاعدة البيانات، ويولّد إجابة عربية طبيعية |
| 📚 **دليل جامعات تفاعلي** | بحث فوري في 60+ جامعة وكلية وقسم مستخرجة من دليل الطالب الرسمي 2026–2027 |
| 💼 **قاعدة وظائف نموذجية** | 40+ وظيفة موزعة على 24 عائلة تخصص، مع المهارات المطلوبة لكل وظيفة |
| 🔍 **تفسير كامل** | عرض المهارات المتطابقة والناقصة لكل توصية |
| 🌙 **دعم الوضع الداكن** | يكيّف نفسه تلقائيًا مع إعدادات النظام |
| 📱 **تصميم متجاوب** | يعمل بسلاسة على الهاتف والحاسوب |
| 🔒 **خصوصية كاملة** | لا يُرسل أي بيانات لخدمات خارجية، كل شيء يعمل محليًا |
| 📖 **توثيق API تلقائي** | Swagger UI عبر `/docs` |
