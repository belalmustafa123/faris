عن النظام

بوصلة الخريج هو نظام ذكي للتوصية بالوظائف لخريجي الجامعات العراقية، صُمم لمساعدة الخريجين على اكتشاف المسار المهني الأنسب.

👨‍💻 المطور

  • الاسم الكامل: فراس هذال وسمي
  • المكان الحالي: العراق، محافظة ديالى
  • الجامعة: جامعة ديالى
  • الكلية: كلية التربية للعلوم الصرفة
  • القسم: قسم الحاسبات والذكاء الاصطناعي

🧠 التقنيات المستخدمة

Python • FastAPI • scikit-learn (TF-IDF + Cosine Similarity) • SQLite • HTML/CSS/JS

🎯 كيف يعمل النظام

١. محرك التوصية: يحوّل وصف كل وظيفة إلى متجه رياضي بـ TF-IDF، ثم يحسب التشابه الجيبي بين ملف الخريج وكل وظيفة.

٢. المساعد الذكي: يصنّف نية السؤال، ويسترجع الإجابة من قاعدة معرفة واسعة، ويلجأ للبحث في الإنترنت عند الحاجة.

⚠️ حدود النظام

• الوظائف النموذجية إرشادية وليست إعلانات شاغرة.

• إعلانات العمل يضيفها الزوار وتُراجع من قبل الإدارة.

• المساعد الذكي يعمل محليًا وقد يستعين بالإنترنت عند الحاجة.
